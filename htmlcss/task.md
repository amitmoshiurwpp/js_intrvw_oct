# HTML/CSS Coding Exercise

## Files

- `index.html`: a page with three cards
- `styles.css`: the existing styles

## Setup

1. Clone the repository.
2. Open `index.html` in a browser.

## Tasks

1. **Responsive layout**: The cards show in three columns on desktop. Change the layout so the cards stack in a single column on mobile screens (600px wide or narrower).
2. **Second card button**: Change the button colour on the second card only to red. The buttons on the other cards must stay the same.
3. **Last card background**: Change the background colour of the last card only to orange.

## Rules

- Make your changes in `styles.css` only. Do not edit `index.html`.
- Do not use inline styles or `!important`.
- Use plain CSS (no frameworks or libraries).

## How to check your work

- Resize the browser window, or use your browser's device toolbar, and confirm the layout changes from three columns to one column at 600px.
- Confirm that only the second card's button is red.
- Confirm that only the last card's background is orange.

## Time

Suggested time: 20 minutes. Afterwards, be ready to explain the approach and selectors you chose.
